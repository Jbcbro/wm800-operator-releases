# WM800 Operator releases

Installers and the auto-update feed for **WM800 Operator**, the operator software
for the WheelRestore WM800 diamond cut lathe. WheelRestore.com · engineered by
HBC-System (hbc-system.com).

This repository contains release files only. The source code is private.

## Install

Download `WM800-Operator-Setup-<version>.exe` from the latest release and run it.

## Updates

Installed copies check this repository for new releases and download them in the
background. An update is installed only after the operator confirms it in
**Settings → Updates**, and only while the machine is idle: on the home screen,
with the spindle stopped and no job running. An update that has been downloaded is
also installed when the app is closed.

The portable build does not update itself; download the installer instead.
